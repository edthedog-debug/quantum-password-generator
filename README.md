# Anonymous Quantum-Grade Password Generator

A secure, zero-knowledge, and completely anonymous password generator running entirely in your browser. 

## Privacy Guarantee
* **Zero Data Collection:** We do not track, log, store, or transmit any data.
* **Client-Side Only:** All passwords are generated locally within your browser using cryptographically secure pseudo-random number generators (`crypto.getRandomValues`).
* **No Cookies / No Analytics:** Absolute privacy with zero external telemetry.
